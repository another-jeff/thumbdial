
          Project description.
         
        Summary:
Designed and built a fully interactive sunburst chart to explore nested permit data during a major system migration. This visualization helped stakeholders make sense of thousands of categories during the data audit and transformation process.

Key Features:
- Zoomable nested chart with smooth transitions
- Clean, responsive layout for browser-based review
- Lightweight, framework-free—pure JavaScript + D3.js

Outcome:
Simplified navigation of deeply nested records and provided a clear visual reference for planning and verification.
